# Página web con el juego de cartas Cosmos

Un juego de cartas de temática espacial de 2 a 4 jugadores que consiste en la creación de sistemas solares. 
Está adaptado para ser jugado en el ordenador desde el navegador web. 

En principio existirá la opción de poder jugarlo solo con el mismo ordenador, pero en un futuro también se podrá jugar contra 
jugadores que estén lejos conectándose online, así como una opción de poder jugar contra el ordenador. 


## Lenguajes usados para la creación del juego

- HTML5
- CSS3
- JavaScript
- Git/GitHub

## Cómo ejecutar el proyecto

Clona este repositorio:

git clone https://github.com/Varya06/JuegoCartasCosmos.git

Después, abre el archivo `menuPrincipal.html` en un navegador web.
